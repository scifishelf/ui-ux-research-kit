# MP01 · Button and press

Duration: **80–140 ms**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Press gives immediate feedback; busy state prevents duplicate completion.

| Variant | Contract |
| --- | --- |
| Desktop | Hover only for hover:hover/pointer:fine; focus remains independently visible. |
| Installed PWA | Use touch :active and the product's 44 CSS px target; hover is not required. |
| Reduced motion | No scaling; border/text change immediately. |

```html
<button class="press" id="MP01">Save change</button>
```

Code: [motion.css](motion.css), [examples.js](examples.js), [examples.tsx](examples.tsx). The [interactive demo](demo.html) uses simulated product states. Preserve native semantics, busy/error behavior and the actual component contract when integrating.

Acceptance: The button can be activated without waiting for animation to finish. Criteria: MOT-01, MOT-02, MOT-03, MOT-04, ACC-03. Sources: S29 in the [source register](../report/source-register.md).

Video: [desktop demo](videos/mp01-desktop.mp4), normal interaction followed by emulated reduced motion. See [capture record](../report/evidence/motion-capture.json) for actual runtime and capture date. An installed-PWA video is not supplied; obtain it in the applicable target runtime before acceptance. The demo does not establish usability or display-fps effects.
