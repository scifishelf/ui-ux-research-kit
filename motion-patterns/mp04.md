# MP04 · Form validation

Duration: **0–160 ms; immediate message**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Offer specific help after blur/submit; avoid startling shake effects.

| Variant | Contract |
| --- | --- |
| Desktop | Use aria-invalid and aria-describedby; place focus meaningfully. |
| Installed PWA | Keep errors near fields and reachable above the keyboard; appropriate next/done input behavior. |
| Reduced motion | Immediate error text/icon; no shaking. |

```html
<label for="mail">Email</label><input id="mail" aria-invalid="true" aria-describedby="mail-error"><p id="mail-error">Enter a complete email address.</p>
```

Code: [motion.css](motion.css), [examples.js](examples.js), [examples.tsx](examples.tsx). The [interactive demo](demo.html) uses simulated product states. Preserve native semantics, busy/error behavior and the actual component contract when integrating.

Acceptance: Errors are associated with fields and correction retains input. Criteria: MOT-01, MOT-02, MOT-03, MOT-04, ACC-03. Sources: S21, S24 in the [source register](../report/source-register.md).

Video: [desktop demo](videos/mp04-desktop.mp4), normal interaction followed by emulated reduced motion. See [capture record](../report/evidence/motion-capture.json) for actual runtime and capture date. An installed-PWA video is not supplied; obtain it in the applicable target runtime before acceptance. The demo does not establish usability or display-fps effects.
