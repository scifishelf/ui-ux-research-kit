# MP10 · Drag and snap

Duration: **Follows pointer; snap 180–300 ms**. Easing: `spring: stiffness 380, damping 38, mass 1`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Direct manipulation stays direct; snap is interruptible.

| Variant | Contract |
| --- | --- |
| Desktop | Pointer capture, keyboard alternatives and feedback beyond dragging. |
| Installed PWA | Use container-appropriate touch-action; do not block scrolling globally. |
| Reduced motion | No residual oscillation; set final position immediately. |
