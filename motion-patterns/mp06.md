# MP06 · Dialog and bottom sheet

Duration: **180–280 ms enter; 120–180 ms exit**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Focus and modal semantics are independent of animation.

| Variant | Contract |
| --- | --- |
| Desktop | Task-appropriate dialog/popover, Escape and focus return. |
| Installed PWA | Use sheets only for suitable tasks; check safe areas and keyboard. |
| Reduced motion | Immediate dialog or brief fade <=100 ms; no large translation. |
