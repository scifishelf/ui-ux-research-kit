# MP11 · Switch and selection

Duration: **100–180 ms**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Show selection immediately without claiming server-confirmed success.

| Variant | Contract |
| --- | --- |
| Desktop | Native checkbox/switch or an existing reviewed control. |
| Installed PWA | Native system controls may have haptics; do not promise freely controlled haptics. |
| Reduced motion | Change state position immediately. |
