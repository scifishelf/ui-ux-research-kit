# MP14 · Voice and analysis feedback

Duration: **100–180 ms state change; continuous only while active**. Easing: `linear or bounded opacity easing`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Feedback truthfully reflects recording/analysis and stops on completion/error.

| Variant | Contract |
| --- | --- |
| Desktop | Text status and visible stop; separate audio permission. |
| Installed PWA | Reachable touch stop; check background/resume and permissions. |
| Reduced motion | Static active indicator with equivalent status. |

```html
<div id="MP14" role="status">Analysis in progress. <button>Cancel</button></div>
```

Code: [motion.css](motion.css), [examples.js](examples.js), [examples.tsx](examples.tsx). The [interactive demo](demo.html) uses simulated product states. Preserve native semantics, busy/error behavior and the actual component contract when integrating.

Acceptance: Stop works and feedback ends on success, cancellation or failure. Criteria: MOT-01, MOT-02, MOT-03, MOT-04, ACC-03. Sources: S21, S22 in the [source register](../report/source-register.md).
