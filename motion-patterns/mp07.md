# MP07 · Page and context transitions

Duration: **160–240 ms**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Transitions clarify location; routing, back and focus work without them.

| Variant | Contract |
| --- | --- |
| Desktop | Same-document transition with a controlled synchronous DOM commit. |
| Installed PWA | Equivalent destination semantics; respect system back gestures and avoid large slide cascades. |
| Reduced motion | Disable View Transitions; set destination/focus immediately. |

```js
await transitionCommit(() => { document.querySelector("#route-title").textContent = "Settings"; });
```

Code: [motion.css](motion.css), [examples.js](examples.js), [examples.tsx](examples.tsx). The [interactive demo](demo.html) uses simulated product states. Preserve native semantics, busy/error behavior and the actual component contract when integrating.

Acceptance: Navigation and meaningful focus work when the API is unavailable. Criteria: MOT-01, MOT-02, MOT-03, MOT-04, ACC-03. Sources: S14, S15, S48 in the [source register](../report/source-register.md).

Video: [desktop demo](videos/mp07-desktop.mp4), normal interaction followed by emulated reduced motion. See [capture record](../report/evidence/motion-capture.json) for actual runtime and capture date. An installed-PWA video is not supplied; obtain it in the applicable target runtime before acceptance. The demo does not establish usability or display-fps effects.
