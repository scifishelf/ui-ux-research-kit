# MP08 · Lists and reordering

Duration: **160–260 ms; total stagger <=120 ms**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Changes clarify position without delaying each item's usability.

| Variant | Contract |
| --- | --- |
| Desktop | Use FLIP/layout animation for few visible changes; tab order follows DOM. |
| Installed PWA | Keep touch scrolling free; update large lists immediately. |
| Reduced motion | Apply positions/items immediately. |
