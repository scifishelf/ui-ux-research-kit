# MP12 · Optimistic save and undo

Duration: **120–180 ms local feedback**. Easing: `cubic-bezier(.2,0,0,1)`. Timing is a pilot heuristic to test, not a universal perceptual standard.

Optimistic changes remain pending until confirmation; failure restores clear state.

| Variant | Contract |
| --- | --- |
| Desktop | Provide status and sufficient undo time; avoid disappearing-only feedback. |
| Installed PWA | Equivalent recovery and reachable undo; account for safe areas in bottom notices. |
| Reduced motion | Immediate status changes. |
